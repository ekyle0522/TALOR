# Tail Cues, Principal Corrections: Plug-and-Play Rectification for Open-Set Test-Time Adaptation (NeurIPS 2026)

This is the official repository for **TALOR** (**T**est-time **A**daptation via **L**inear **O**nline **R**ectification), a lightweight, backward-free feature rectification method for open-set test-time adaptation.

**Code Release:** The implementation and instructions for reproducing the experiments are currently being prepared and will be made available in this repository.
